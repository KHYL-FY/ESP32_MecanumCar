# 故障诊断：车"卡一下""推杆没反应"怎么查

> 这类问题的麻烦之处是：**发生只有几百毫秒，人来不及看屏幕**。
> 所以固件里加了个事件日志，把异常和当时的电压记下来，事后按 `g` 回看。

---

## 一、先看事件日志

串口敲 `g`：

```
---- 事件日志（最早的在上）----
   12.4 s  手柄超时   电压 7.12V  断了 820ms
   47.9 s  手柄超时   电压 7.05V  断了 1240ms
---- 统计 ----
  手柄超时次数   = 2
  最长一次断连   = 1240ms
  电池过低次数   = 0
  行驶中最低电压 = 6.58V
-----------------
（打 g 会清空日志）
```

**三条关键信息：**

| 字段 | 看什么 |
|---|---|
| `手柄超时次数` | **0** = 链路一直好，问题不在遥控 |
| `最长一次断连` | **> 1000 ms** = 典型的链路/干扰问题（正常抖动只有几十 ms） |
| `行驶中最低电压` | < 6.4 V = 电池被电机启动拉垮了（电源问题） |

---

## 二、判读表：一次对号入座

| 日志表现 | 结论 | 处理 |
|---|---|---|
| 手柄超时次数 **> 0**，最长断连 **> 1 秒** | **链路 / EMI** | 补 100 nF 电容、接收器天线远离电机线、电机线绞合 |
| 手柄超时 **0 次**，最低电压 **< 6.4 V** | **电池被拉垮** | 充电；或按 `k` 把输出上限降到 150~180 |
| 手柄超时 **0 次**，电压也正常 | **机械 / 接线** | 齿轮箱冷脂、轮子卡东西、某路电机线松动（按 `1 2 3 4` 单独试） |
| 有 `电池过低` 记录 | 真的过放了 | 立刻充电，别再用 |

> ⚠️ 电压那一列**需要先接分压电阻并启用监测**（按 `b`）。
> 没接的话日志里是 `电压 --`、`行驶中最低电压 --`，这时只能靠"手柄超时次数"区分链路和其他。

## 三、真实案例：冷启动时"动一下、卡一下"

**现象**：静置三天后首次试车，推杆车只动一下就停，反复几次后才正常。

**不是电容的原因**：EMI 是**持续存在**的干扰源，不会"试几遍就好"。
能自己好的问题，通常是**有状态量在变化**的：温度、电压、链路建立。

### 三个候选原因

| # | 原因 | 机制 | 为什么几次之后会好 |
|---|---|---|---|
| 1 | **电池低温 + 降压欠压** | 静置自放电 + 室温低 → 电压偏低；启动瞬间拉 4~6 A，5 V 输出跌破 → 电机没劲 → 电流回落 → 电压回升，如此往复 | 电池内部升温、内阻下降；几次冲击后电压恢复 |
| 2 | **齿轮箱润滑脂冷硬** | 1:48 减速箱用的是普通润滑脂，低温变稠，静摩擦大，`minDuty=45` 带不动 | 跑几轮脂被搅开 + 电机发热 → 变顺 |
| 3 | **蓝牙链路刚上电不稳** | 手柄/接收器开机后还在建立链路，前几秒丢帧 → 300 ms 超时 → 停车 | 几秒内链路稳定 |

### 怎么区分

```
看事件日志：
  ├─ 有"手柄超时"记录  → 3（链路）
  └─ 没有              → 1 或 2（电源/机械）

再摸一下：
  ├─ 齿轮箱冰凉、低速推不动，跑一会儿就好  → 2
  └─ 电池电压偏低（< 7.2V）、推杆时跌破 6.8V → 1
```

## 四、冷天起步的标准流程（建议每次照做）

```
① 电池充满，出门前别放在冰凉的地上
② 车架空，低速空转 20~30 秒 —— 把润滑脂搅开、电机预热
③ 万用表量一次电池，低于 7.0 V 就先充
④ 落地，从小油门开始，前 30 秒别满杆
```

第三条尤其重要：**2S 锂电在低温下内阻会翻倍**，容量看起来"还有"，一拉就塌。

---

## 五、通用排查顺序

出任何"不工作"的问题，按这个顺序查，别乱跳：

```
① 电源：VM = 5V？VCC = 3.3V？STBY = 3.3V？共地了？
② 信号：串口四轮输出数字会不会变？（会变说明软件正常）
③ 机械：轮子能不能用手转动？有没有卡东西？
④ 链路：数据龄 < 20ms？（看事件日志）
⑤ 参数：按 v 看配置有没有被调乱，按 d 恢复默认
```

## 六、日志的局限

- **只记 8 条**，满了覆盖最旧的。长时间跑不建议一直开着看。
- 断连 **< 400 ms 的不记录**（正常蓝牙抖动就会到这个量级，记了全是噪声）。
- 只在**刚触发**时记一次过放，不会每秒刷屏。
- 断电就清空（存在 RAM，不写 NVS —— 避免频繁擦写闪存）。
