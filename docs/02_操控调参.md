# 阶段 4：操控调参（不用改硬件）

> 车已经能跑了。这一步把它从"能动"调到"好开"。
> **所有参数改完立刻生效、自动存 NVS，断电和重新烧录都不丢。**

---

## 一、四个参数

| 参数 | 命令 | 范围 | 作用 |
|---|---|---|---|
| **输出上限** | `k` 减 / `K` 加 | 60~255 | 最高速。降下来，车更慢更可控 |
| **偏航修正** | `z` 减 / `Z` 加 | -30~+30 | 前进跑偏的差速补偿。**正数=往右修** |
| **摇杆曲线** | `x` 减 / `X` 加 | 0~80 | 中位越细腻、末端越激进 |
| **转向力度** | `y` 减 / `Y` 加 | 40~100% | 原地转的降额，麦轮原地转非常快 |

改的时候串口会打印：

```
>>> 偏航修正 = +3（正数=往右修，负数=往左修）
[配置] 已保存到 NVS
```

按 `v` 可以随时看全部当前值。

---

## 二、调参顺序（很重要，顺序错了会来回改）

```
① 先降速度上限  ← 必须第一个做
② 再修跑偏
③ 再调摇杆曲线
④ 最后调转向力度
```

### ① 降速度上限（`k`）

**为什么先做这个**：车速太快时，任何其他参数都看不出效果——车一窜就撞墙，你判断不了"偏多少"。

```
按住 LB，左摇杆推到底，看车速
太快 → 按 k 每次 -10，再试
建议新手落在 150~180
```

判断标准：**满杆能跑满整个房间，还有余量控制方向**。

### ② 修跑偏（`Z` / `z`）

```
在一条长直线上（地板缝、地砖线）低速前进 2~3 米
看车头偏向哪边：
  往左偏 → 按 Z（往右修），每次 +1，直到走直
  往右偏 → 按 z
```

**只修前进/后退**，横移和原地转不受影响（代码里限制了）。

为什么会有跑偏：四个 TT 电机绕组 3~10 Ω，差异 3 倍，同样 PWM 下转速不同。这是开环系统的固有问题，**只能用差速补偿近似修正**，不能彻底消除。

判断标准：**3 米内偏离不超过半车身宽**就算调好了。

### ③ 摇杆曲线（`X`）

```
问题：中位附近一碰就窜 → 按 X 加 expo
问题：推到底感觉不够猛 → 也按 X（末端更激进）
问题：想线性、所见即所得 → 按 x 减到 0
```

推荐：**先 20~30**。曲线公式是：

```
out = (1-k)·x + k·x³     k = expo/100
```

| expo | 手感 |
|---|---|
| 0 | 线性，最直观 |
| 20~30 | 中位细腻，末端不变慢（**推荐**） |
| 50+ | 中位非常细腻，末端很猛（高手向） |

### ④ 转向力度（`y`）

```
按住 LB 推右摇杆，看原地转的速度
转得发飘、控制不住 → 按 y 降（每次 -5）
建议 70~85%
```

麦轮的原地转比普通车快得多（四个轮子全部出力在旋转），降额之后反而"看起来更听话"。

---

## 三、调完之后

按 `v` 把配置抄进 [标定记录表](03_标定记录表.md)，以后重烧固件、换电池、换场地都不用重新调。

如果哪天调乱了：按 `d` 恢复默认（方向也会恢复成"全正转"，要重新标一遍四轮方向）。

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `K` 按到 255 还是慢 | 电池电量低 | 充电。2S 锂电低于 7.0V 就开始没劲 |
| 修了偏航还是偏 | 偏航只是差速补偿，不能消除 | 检查麦轮辊子朝向（左右必须镜像）、地面是否打滑 |
| 低速推杆不转，推过 20% 才动 | 死区补偿不够 | 按 `m` 把最小占空比调到 70 |
| 加 expo 后车"起步一顿" | 曲线的陡峭段 + 死区 | 先按 `m` 调死区，再调 expo |
| 调完手感变了但重启就恢复 | 没保存 | 任何 `x/X z/Z y/Y k/K` 都会自动保存；只有 `d` 会重置 |
