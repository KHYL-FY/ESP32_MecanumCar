## 一、电机焊接记录

**判读标准**：量两根线头之间 = **1~20 Ω** 正常；`0.0 Ω` = 短路；`1`/`OL` = 虚焊断路。
再拽一下线（约 0.5 kg 力），不能动。

| # | 位置 | 标签 | 线头间电阻 | 拽线 | 线头↔金属壳 | 备注 |
|---|---|---|---|---|---|---|
| 1 | 练手第一个 | （待贴） | **13 Ω** ✅ | ✅ | ✅ 不导通 | 2026-10-22 测得 |
| 2 | 左前 | `LF` | 3~10 Ω ✅ | | | 四个全部焊完 |
| 3 | 右前 | `RF` | 3~10 Ω ✅ | | | |
| 4 | 左后 | `LR` | 3~10 Ω ✅ | | | |
| 5 | 右后 | `RR` | 3~10 Ω ✅ | | | |

**2026-10-22 补测：四个电机全部落在 3~10 Ω，无短路、无开路 → 焊接合格。**

> ⚠️ 3 Ω 和 10 Ω 相差 3 倍多，同一个 PWM 下**转速会不一样**（低阻的转得快）。
> 结果就是：直行时车会往一边偏。无编码器做不到闭环修正，但可以在固件里加"每轮微调系数"补偿（后面再定）。
> 另外 3 Ω 的电机堵转电流约 1.7 A（5 V），四个一起堵转就超了 2 A 降压的能力 ——
> **别让车顶住墙还一直推摇杆**。

> 四个电机的电阻不必相同，**相差一两欧是正常的**（绕组 + 电刷接触差异）。
> 但若某个明显偏小（比如 2 Ω vs 其他 13 Ω），说明那个电机可能有问题。

## 三、行驶表现记录

| 日期 | 现象 | 数值/参数 | 处理 |
|---|---|---|---|
| 2026-10-22 | 首次落地，前进/后退/横移/原地转均正常 | 默认参数 | ✅ 通过 |

例如：

- 前进时车往左偏 → 右前轮实际转速偏慢（TT 电机个体差异，无编码器无法闭环）
  → 用 `Z` / `z` 调偏航修正（见 [02 操控调参](02_操控调参.md)）

- 原地转时车身有轻微平移 → 麦轮辊子摩擦差异，正常现象
